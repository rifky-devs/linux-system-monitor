# Linux System Monitor

A lightweight Linux system monitoring dashboard built with JavaScript, Node.js, and Express.js.

## Features

- Hostname monitoring
- Operating system information
- CPU core information
- RAM usage
- System uptime
- REST API
- Web dashboard

## Tech Stack

- JavaScript
- Node.js
- Express.js
- HTML
- CSS
